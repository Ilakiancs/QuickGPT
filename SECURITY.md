# Security Policy

## Supported versions

Only the [latest release](https://github.com/Ilakiancs/QuickGPT/releases/latest) receives fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/Ilakiancs/QuickGPT/security/advisories/new),
not as a public issue. Include the QuickGPT version, your macOS version, and steps to reproduce.
